## Narayanastra

#### Your codebase. Your machine. Your control.

**Narayanastra** is an open-source, local-first coding agent designed to explore codebases, understand software issues, propose code changes, run tests, and iteratively repair bugs using locally running open-weight language models.

Inspired by the **Mahabharata**, _One of the closest matches to an autonomous weapon. In the Mahabharata, it unleashes a multitude of weapons against its targets, and resistance can provoke a stronger attack. Its behaviour is governed by divine rules rather than continuous manual control._

> **An agent of precision. A weapon against bugs.**

---

#### Capabilities

| Component | Purpose |
|---|---|
| Astra Engine | Agent orchestration and tool calling loop |
| Drishti | Repository navigation and code understanding |
| Sankalpa | Task planning and execution tracking |
| Pariksha | Test execution and result verification |


## Usage

```bash
# Ask the agent to fix a bug
narayanastra "Find and fix the pagination bug"

# Request tests for edge cases
narayanastra --model local "Add tests for empty inputs"

# Review proposed changes
narayanastra --review
```
